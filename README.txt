KURIER-START — бесплатная статическая информационная сборка

В этой версии нет анкеты и формы сбора заявок. На сайте указан телефон для прямого звонка и ссылки WhatsApp/Telegram. Сайт сам не принимает, не хранит и не пересылает введённые пользователем контактные данные.

Размещение: статический сайт. Главный файл — index.html. Все ресурсы подключаются относительными путями. Можно размещать на бесплатном статическом хостинге (например, GitHub Pages) при наличии доступа к аккаунту.

Домен kurier-start.ru выбран как желаемый, но не зарегистрирован и не подключён. Бесплатный хостинг не делает регистрацию собственного домена бесплатной; до регистрации можно использовать бесплатный поддомен хостинга.
