# Курьер — независимая информационная страница

Сайт помогает кандидатам ознакомиться с направлениями работы курьером во ВкусВилл и связаться с независимым контактным лицом. Это не официальный сайт и не представительство ВкусВилл.

Публикация: GitHub Pages.

## SEO и контроль публикации

- Публичный sitemap: https://76kovka76-hub.github.io/kurier-start/sitemap.xml
- После каждого существенного обновления проверь статус GitHub Pages и открой главную и новые страницы на телефоне и компьютере.
- В Яндекс Вебмастере и Google Search Console подтверди права на сайт, отправь sitemap и проверь отчёты об индексировании и проблемах.
- Раз в неделю фиксируй показы, клики, CTR, среднюю позицию и поисковые запросы отдельно для главной, памяток и калькулятора.
- Не создавай страницы городов с выдуманными вакансиями, зарплатами или одинаковым шаблонным текстом. Добавляй региональные страницы только при наличии проверяемых уникальных данных.
- Не подключай стороннюю аналитику или формы сбора заявок без отдельной оценки приватности и законных оснований.

Search Console и Яндекс Вебмастер требуют ручного подтверждения владельца сайта; автоматическое подключение здесь не выполняется.
